# Portail en ligne - créer son compte, se connecter, mot de passe oublié, double authentification

## En bref
Le portail en ligne de la caisse type permet aux assurés et aux employeurs de faire leurs démarches sans papier : demande de rente (KB-02), annonce d'un changement de revenu (KB-04, KB-05), demande d'extrait de compte (KB-06), déclaration des salaires (KB-09). La connexion demande une adresse e-mail, un mot de passe et un second facteur (double authentification).

Toutes les valeurs de cette fiche (délais, nombre d'essais, longueurs) sont propres à la caisse type, qui est fictive.

## Ce qu'il faut savoir

### Créer son compte
1. Sur la page d'accueil du portail, choisir « Créer un compte » et le profil : assuré ou employeur.
2. Saisir son adresse e-mail et son numéro de téléphone mobile, puis confirmer l'adresse e-mail avec le lien reçu.
3. La caisse envoie par courrier postal une lettre avec un code d'activation, valable 30 jours. Le courrier garantit que le compte est ouvert par la bonne personne.
4. Saisir le code d'activation, choisir un mot de passe, puis configurer le second facteur.

### Se connecter et double authentification
- Le second facteur est un code à usage unique, reçu par une application d'authentification (recommandé) ou par SMS.
- Lors de la configuration, le portail affiche des codes de secours : les conserver en lieu sûr, hors de l'ordinateur.
- Mot de passe : 12 caractères au moins ; il ne doit pas être réutilisé d'un autre site.

### Mot de passe oublié
- Choisir « Mot de passe oublié » sur la page de connexion et saisir son adresse e-mail.
- Le lien de réinitialisation est valable 1 heure. S'il n'arrive pas : vérifier le dossier des courriers indésirables, puis refaire la demande.
- Le second facteur reste demandé après la réinitialisation.

### Compte bloqué
- Après 5 essais de connexion manqués, le compte est bloqué 30 minutes, puis se débloque tout seul.

### Problèmes fréquents et premiers gestes
- Page blanche ou bouton qui ne réagit pas : utiliser une version récente de Chrome, Firefox, Edge ou Safari, vider le cache, désactiver le bloqueur de publicité pour le portail.
- Code de double authentification refusé : vérifier que l'heure du téléphone est réglée automatiquement (une horloge décalée fausse les codes).
- Lien d'activation ou de réinitialisation expiré : refaire la demande, un seul lien est valable à la fois.
- Maintenance : les interruptions prévues sont annoncées à l'avance sur la page de connexion.

### Employeurs : gérer les accès
- Le premier compte employeur devient administrateur. Il ajoute et retire les accès de ses collaborateurs depuis « Gestion des utilisateurs ».
- Quand un collaborateur quitte l'entreprise, l'administrateur retire son accès le jour même.

### Sécurité
- La caisse ne demande jamais un mot de passe, un code de double authentification ou un code de secours, ni par téléphone, ni par e-mail, ni dans le chat.
- Un e-mail ou un SMS suspect qui se fait passer pour la caisse ne doit pas être ouvert : le signaler à la caisse et le supprimer.

## Quand passer la main à un conseiller
- L'agent ne demande jamais de mot de passe ni de code. Si la personne en donne un, l'agent lui conseille de le changer tout de suite.
- Perte du téléphone ou du second facteur sans code de secours : la caisse doit vérifier l'identité de la personne, ce que l'agent ne peut pas faire. Ouvrir un ticket pour le support du portail.
- Soupçon d'accès frauduleux au compte (connexion inconnue, données modifiées) : ticket de priorité haute pour le support du portail.
- Erreur technique qui persiste après les premiers gestes : ouvrir un ticket avec le message d'erreur exact, l'heure, le navigateur et sa version, l'appareil utilisé et les gestes déjà essayés. Pas de capture d'écran contenant des données personnelles.
- Lettre d'activation jamais reçue ou adresse postale à changer.
